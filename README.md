# **Human–AI Text Analysis**

Reusable and documented Python templates for computational text analysis in Human–AI research.

# What is this?
This repository provides research-oriented code templates that can be adapted to different textual datasets.
The goal is to make computational text analysis transparent, reproducible, and accessible to researchers without sharing restricted research data.

# Current Templates
Topic Modeling
Includes:
LDA — probabilistic topic modeling,
NMF — TF-IDF-based topic modeling,
BERTopic — embedding-based topic modeling.
See 01_topic_modeling for the code and detailed instructions.
